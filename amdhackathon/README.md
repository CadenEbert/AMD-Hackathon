# Amdhackathon

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.3.


## Project Set-Up

DOWNLOAD ANGULAR AND NODE.JS

1. CREATE 2 TERMINALS
2. CD INTO amdhackathon
3. ng serve starts frontend
4. npm run server starts backend
5. `http://localhost:4200/` is how to see the application

BACKEND is the backend
'ng g c component-name' creates component
'ng g s service-name' creates service
